
# Junior C++ Developer — Self‑Assessment Checklist

## Scoring Template

For each section, score yourself:
0 – No experience
1 – Basic understanding
2 – Can apply with guidance
3 – Independent and reliable
4 – Advanced; can work independently and mentor others
5 – Expert; Language Guru level


## Core C++ Language Fundamentals
* [ ] I can explain stack vs heap and when each is used
* [ ] I can write and use classes, constructors, destructors
* [ ] I understand inheritance, virtual functions, and polymorphism
* [ ] I know the difference between downcasting and upcasting in polymorphic hierarchies
* [ ] I can use const correctly (methods, variables, pointers)
* [ ] I know how to avoid common UB traps (dangling pointers, double delete, out‑of‑bounds)
* [ ] I know how to overload operators in C++ (e.g., +, -, ==, <<, >>)
* [ ] I know how to use cast operators (static_cast, dynamic_cast, const_cast, reinterpret_cast)

## Modern C++ Essentials
* [ ] I understand move semantics at a conceptual level
* [ ] I know what RAII is and why it matters
* [ ] I understand auto and basic type deduction, range‑based loops, and structured bindings

## Standard Library & STL
* [ ] I can use std::vector, std::string, std::array, std::map, std::unordered_map
* [ ] I know how to choose the right container for a task
* [ ] I understand iterators and iterator invalidation
* [ ] I can use algorithms like sort, find, transform, accumulate

## Tooling & Environment
* [ ] I can use Git (branching, merging, resolving conflicts)
* [ ] I can debug with GDB or an IDE debugger
* [ ] I can use sanitizers like AddressSanitizer or UndefinedBehaviorSanitizer

## Computer Science Foundations
* [ ] I understand Big‑O complexity
* [ ] I can implement basic data structures (list, stack, queue)
* [ ] I understand how hash tables and trees work conceptually
* [ ] I can reason about algorithmic efficiency

## Multithreading & Concurrency
* [ ] I know what a race condition is
* [ ] I understand mutexes and locks at a basic level
* [ ] I know how to start and join a thread using std::jthread

## Software Engineering Habits
* [ ] I write readable, consistent code
* [ ] I can explain my design decisions
* [ ] I can read and understand someone else’s code
* [ ] I can ask good questions and collaborate in a team
* [ ] I can follow coding guidelines (e.g., Google C++ Style Guide)
